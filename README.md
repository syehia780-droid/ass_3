# 🎓 Student Management System

A simple **Java Console Application** that simulates a Student Management System using Object-Oriented Programming (OOP). The project demonstrates the core concepts of Java, including classes, objects, constructors, arrays, methods, loops, conditional statements, and switch-case.

## 🚀 Features

* Add and manage multiple students.
* Display all students with their information.
* Calculate the average grade of all students.
* Find the student with the highest grade.
* Search for a student by ID.
* Validate user input (grades must be between 0 and 100).
* Display grade status based on the student's score:

  * **90 - 100** → Excellent
  * **75 - 89** → Very Good
  * **60 - 74** → Pass
  * **Below 60** → Fail

## 📋 Main Menu

```text
1. Display Students
2. Calculate Average Grade
3. Find Highest Grade
4. Search Student by ID
0. Exit
```
